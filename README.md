# Driver Guardian

Hệ thống phát hiện và cảnh báo tình trạng buồn ngủ của tài xế sử dụng Deep Learning.

## Giới thiệu

Driver Guardian là hệ thống hỗ trợ giám sát trạng thái tài xế trong quá trình lái xe, nhằm phát hiện các dấu hiệu buồn ngủ và đưa ra cảnh báo kịp thời.

Hệ thống được xây dựng theo kiến trúc phân tầng gồm:

- Mô-đun AI xử lý dữ liệu từ camera và đưa ra kết quả nhận diện.
- Ứng dụng Android Automotive hiển thị thông tin, trạng thái giám sát và cảnh báo.
- FastAPI Backend cung cấp các API nghiệp vụ.
- Oracle Database lưu trữ dữ liệu tài xế, phương tiện, chuyến đi và các sự kiện cảnh báo.
